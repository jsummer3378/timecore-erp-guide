02 / Setup Guide

完成首次啟用

員工收到 Time Core 邀請後，先設定自己的密碼，再選擇電腦版或手機版使用方式。

STEP 01

員工設定登入密碼

開啟 Time Core 寄送的邀請信，依畫面指示設定自己的密碼。完成後即可使用員編與密碼登入。

若沒有看到信件，請先檢查垃圾郵件匣。

STEP 02

電腦版：登入後下載 ERP

前往 Time Core 登入頁面，登入後依畫面右上方的下載選項安裝電腦版 ERP。

開啟登入頁面 ↗

STEP 03

手機版：加入主畫面

用手機瀏覽器登入 ERP，點選瀏覽器的「分享」按鈕，再選擇「加入主畫面」。之後可像一般 App 一樣開啟。

iPhone：Safari 分享 → 加入主畫面。
